# Review instructions

Read with `CLAUDE.md` (repo guide) and `CONTRIBUTING.md`. This file tunes
Claude Code Review for this repository; it is read from the base branch.

## What Important means here

Reserve Important for findings that would change what a user's visual test
reports or does: a snapshot that passes when it should not (or the reverse),
a wrong verdict wording (an identical DOM called "render noise" when the
styles were not compared, or when the diff is concentrated in one area or
large, or when the dimensions changed), a results.json field that breaks the
documented schema, an exit code that disagrees with
`packages/witness/src/commands/exit-codes.ts`, a baseline written or
approved without the human confirmation the MCP tools require, or a GitHub
Action that would post, commit or push on a token it should not. Style,
naming and refactoring suggestions are Nit at most.

## Cap the nits

Report at most five Nits per review.

## Do not report

- Anything CI already enforces: Biome lint, `tsc`, Jest, the packed-tarball
  consumer install, the `action/dist` sync check
- `action/dist/index.js` and `action/dist/review.cjs`: generated by esbuild
  and committed on purpose; review `action/src/` instead
- `pnpm-lock.yaml` and `.changeset/*.md`
- Test-only code that intentionally violates production rules, and the
  fixtures under `packages/witness/src/__tests__/fixtures/`
- The Python, Ruby and Java adapters' packaging files

## Always check

- A change to a published package's public API or to results.json comes
  with a changeset (`.changeset/*.md`) at the right bump: a schema addition
  is a minor bump of `@testivai/witness`, a removal or type change a major
- The results.json schema is documented identically in three places:
  `docs/extension-api.md`, the "results.json schema" block in `CLAUDE.md`
  and the "Public contract" block in `AGENTS.md`; a change to one without
  the other two is Important
- A change to `action/src/` comes with a rebuilt `action/dist/`
- New behaviour has a unit test, and a new public export has JSDoc
- No reference to a hosted product, dashboard, account or API key, and no
  feature described as paid or gated: the packages are local-first and free
  to use (`docs/philosophy.md`, "Free and open source"); AI explanation is
  bring-your-own-model through `@testivai/mcp`
- `pnpm` everywhere except inside `action/`, which uses plain `npm`
- Verdict wording stays consistent across the HTML report
  (`packages/witness/src/report/template.ts`), the MCP server
  (`packages/mcp/src/lib.ts`) and the PR comment (`action/src/comment.ts`):
  shared rules live in `packages/witness/src/report/` (`diff-shape.ts`,
  `size-mismatch.ts`) and should be reused, not re-derived

Agent setup guide

Pixel-exact mode

Playwright, WebdriverIO, Selenium and testivai witness captures are stabilized by default (animations, transitions, caret, web fonts). Other dynamic content (timestamps, ads, rotating images) still shows up as a diff until you configure it.

Noise is labeled, not removed: DOM unchanged with matching computed styles means likely render noise only when the diff is also small and scattered; a diff concentrated in one area, or over 1% of pixels, gets its own verdict. When styles were not compared, a stylesheet-only change is not ruled out. A capture whose web fonts or stylesheets failed to load reads Unhealthy capture, never noise.

To reduce noise:
• Add ignoreSelectors or mask for dynamic elements
• For variable-height regions, ignore them with mode: "collapse" (@testivai/witness-playwright only)
• Raise threshold, or set maxDiffPercent / maxDiffPixels / shiftTolerance in .testivai/config.json
